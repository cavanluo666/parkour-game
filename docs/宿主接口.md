# 宿主接口约定

`games/parkour` 不是一个独立应用，而是挂在宿主 Web 系统上的**游戏插件**。
本文档列出宿主必须提供的模块与函数。契约很薄：**3 个模块、6 个函数**。

宿主要做的只有两件事：

1. 提供下面这些模块（放在可导入路径上）；
2. 在启动时扫描 `games/` 目录，import 每个子目录里的 `server.py`，
   取出其中的 `Game` 类并实例化，然后调用它的两个注册方法。

---

## 1. 游戏插件与宿主的交界

`server.py` 从宿主导入三样东西：

```python
from db import execute, query          # 数据库
from games.base import BaseGame        # 游戏基类
from logger import get_ip, log_game_score  # 日志
```

宿主调用插件的方式是：实例化 `Game`，然后传入 Flask 蓝图与 SocketIO 实例：

```python
game = Game(key="parkour", meta=json.load(open("games/parkour/game.json")))
game.register_routes(bp)                       # bp 的 url_prefix 应为 /api/game/parkour
game.register_socketio(socketio, "/game/parkour")
```

`BaseGame` 至少要提供：

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `__init__(self, key, meta=None)` | 方法 | 至少要接受 `key`，并把 `meta` 存下来 |
| `self.key` | 属性 | 游戏标识，本插件取 `"parkour"`，用于数据库分区 |
| `register_routes(self, bp)` | 方法 | 用 `@bp.route(...)` 注册 REST 路由 |
| `register_socketio(self, socketio, namespace)` | 方法 | 用 `@socketio.on(..., namespace=...)` 注册事件 |

## 2. `db` 模块

只需要两个函数。数据库建议用 SQLite。

### `execute(sql, params=()) -> None`

执行一条写入 / DDL 语句并提交。本插件会传入 `?` 占位符的参数元组：

```python
execute(
    "CREATE TABLE IF NOT EXISTS game_scores("
    "id INTEGER PRIMARY KEY AUTOINCREMENT,"
    "game_key TEXT NOT NULL,"
    "student_name TEXT NOT NULL,"
    "score INTEGER NOT NULL DEFAULT 0,"
    "detail TEXT,"
    "created_at TEXT)"
)

execute(
    "INSERT INTO game_scores(game_key, student_name, score, detail, created_at) "
    "VALUES(?,?,?,?,?)",
    (game_key, name, score, detail, created_at),
)
```

参考实现（SQLite，注意线程安全）：

```python
import sqlite3, threading

_lock = threading.Lock()
_conn = sqlite3.connect("data/app.db", check_same_thread=False)
_conn.row_factory = sqlite3.Row

def execute(sql, params=()):
    with _lock:
        _conn.execute(sql, params)
        _conn.commit()
```

### `query(sql, params=(), one=False)`

读取数据。**必须返回支持按列名取值的行对象**（`sqlite3.Row` 或 `dict` 均可），
因为插件里用了 `row["student_name"]`、`row["best"]` 这种写法。

- `one=False`（默认）→ 返回行的**列表**（可为空列表）；
- `one=True` → 返回**单行**，没有结果时返回 `None`。

```python
def query(sql, params=(), one=False):
    with _lock:
        cur = _conn.execute(sql, params)
        rows = cur.fetchall()
    if one:
        return rows[0] if rows else None
    return rows
```

### 表结构

宿主**不需要**预建表，插件会在首次使用时执行 `CREATE TABLE IF NOT EXISTS`。
但如果你希望自己管理迁移，表结构是：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | 主键 |
| `game_key` | TEXT NOT NULL | 游戏标识，本插件写 `"parkour"` |
| `student_name` | TEXT NOT NULL | 玩家显示名（清洗后 ≤16 字符） |
| `score` | INTEGER NOT NULL DEFAULT 0 | 分数，夹紧在 0 ~ 1000000 |
| `detail` | TEXT | 例如「距离 123 米，金币 8 枚」 |
| `created_at` | TEXT | ISO 8601，秒级精度 |

## 3. `logger` 模块

| 函数 | 说明 |
| --- | --- |
| `log_game_score(game_key, name, score, ip=None)` | 打印一条成绩日志。本插件调用时用的是关键字参数 `ip=`。 |
| `get_ip()` | 返回当前请求的客户端 IP（无请求上下文时插件已自行 try/except 兜底）。 |

最小实现：

```python
from flask import request

def get_ip():
    return request.remote_addr if request else None

def log_game_score(game_key, name, score, ip=None):
    print(f"[{game_key}] {name} 得分 {score} (ip={ip})")
```

> 注意：`log_game_score` 是**位置参数**调用（`log_game_score(game_key, name, score, ip=ip)`），
> 但 `ip` 用了关键字。请保持参数名一致。

## 4. 路由与命名空间约定

| 项目 | 约定值 |
| --- | --- |
| REST 前缀 | `/api/game/parkour`（`bp` 的 `url_prefix` 由宿主传入） |
| SocketIO 命名空间 | `/game/parkour` |
| 页面路径 | `/game/parkour`（宿主用 iframe 承载 `static/index.html`） |

插件内部注册的是相对路径（`/ping`、`/leaderboard`、`/score`），
所以**宿主负责拼前缀**。SocketIO 那边命名空间是显式传入的。

## 5. 前端对宿主的可选依赖

`static/index.html` 会尝试从父页面读取玩家名（读不到就退回 `localStorage`，再退回默认值）。
这些元素**都是可选的**，宿主没有也不影响游戏运行：

| 来源 | 说明 |
| --- | --- |
| `#studentWelcome` | 形如「张三，欢迎您！」的欢迎语，插件会用正则去掉后缀 |
| `#studentName` / `#userName` | 直接放置姓名的元素 |
| `localStorage` | 依次尝试 `parkour_name`、`student_name`、`studentName`、`student`、`name`、`username` |

父页面跨域或读取受限时，插件的 `try/catch` 会静默兜底，不会报错。
**如果你不打算采集真名，请不要提供这些元素**，让玩家自行输入昵称。

## 7. 快速验证

宿主接好之后：

```bash
curl http://127.0.0.1:5000/api/game/parkour/ping
# => {"ok":true,"game":"parkour","online":0}
```

再打开 `/game/parkour`，页面顶部显示「已连接大厅」即打通。
